Assumptions for terraform:


You already have:

An Azure Subscription with contributor access.

Azure CLI and Terraform CLI installed (or using ARM via Azure Portal/CLI).

Access to an Azure DevOps project or Git repo to store IaC code.

Naming conventions:

Resource Group: rg-webapp-demo

App Service Plan: asp-webapp-demo

Web App: demo-webapp-001

Deployment region: East US (can be parameterized).

For Terraform → State will be stored in Azure Storage account (for team collaboration).
